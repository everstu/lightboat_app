# 本地与 WebDAV 备份恢复

本地导入/导出与 WebDAV 使用相同的未加密 ZIP 格式。WebDAV 为手动上传/恢复，不做后台自动同步或自动合并；入口位于配置管理标题栏右侧的云朵图标。

## 使用

1. 填写已有的 WebDAV 备份父目录、账号和密码或应用专用密码。上传时自动创建 `lightboat/` 子目录；设置只保存在本机，密码不进入备份。可先“测试连接”，再上传本机备份。
2. 第一台设备点击“上传本机备份”。备份生成时关闭当前网页，等待已接受的 GM 写入完成后取得一致快照。
3. 第二台设备安装兼容版本，填写同一 WebDAV 地址和账号，点击“从远端恢复”。下载和完整校验后展示来源设备、时间、配置/脚本/存储数量；可选择恢复哪些可选内容，确认后替换所选内容。
4. 确认后直接恢复所选内容，不生成本机撤回备份。需要自行保留旧数据时，可先手动“导出备份”。

服务端文件固定为父目录下的 `lightboat/lightboat-backup.zip`。父目录须已存在；客户端使用 PROPFIND 检查子目录，只在上传且子目录缺失时用 MKCOL 创建，重复上传复用同一目录；两台设备同时创建时复查已存在的目录。测试连接只读，不创建目录。请使用最终父目录地址，客户端不跟随重定向，也不会将账号发送到重定向目标。支持 HTTP/HTTPS 与 HTTP Basic 认证；没有浏览器登录、OAuth、表单登录或自签名证书放行功能。标准 HTTPS 传输仍使用系统证书校验。

配置管理的“导出备份”先选择内容，再由系统文件选择器保存 ZIP；“导入备份”支持本地 ZIP 文件或直接下载 ZIP 的在线链接，使用相同校验和事务恢复流程。也兼容旧版 UTF-8 JSON 配置（含 BOM，最多 1 MiB），保留其原有仅替换配置的语义。

## 备份与恢复选项

- 配置和脚本库必选，包含分类、收藏、排序、UA、平台、脚本引用及启用状态。
- 脚本数据可选，包含 GM 设置、自定义规则及规则缓存，作为一组处理，不能从任意脚本存储中通用分离规则与设置。
- 界面偏好可选，包含分类筛选与收藏筛选。

本地导出和 WebDAV 共用并记住备份选项；恢复时只允许勾选包中实际包含的部分。未包含或未勾选的部分保留接收设备的现有数据。“包含空脚本存储”与“未包含脚本存储”有明确区别；前者在确认恢复后清空该部分，后者不修改它。恢复前不自动导出或压缩本机数据，也没有撤回入口；旧版自动保留的 `webdav-local/` 在启动时后台清理，手动导出的备份不受影响。

## 同步范围

| 包含 | 不包含 |
| --- | --- |
| 所有配置、分类、收藏、排序、上次使用项、UA/平台 | 网页 Cookie、登录态、localStorage、IndexedDB、Cloudflare 验证结果 |
| 共享脚本库、脚本引用 ID、顺序与启用开关 | 下载的脚本源码、require/resource 文件版本 |
| GM 持久值，包括脚本设置、自定义规则及其规则缓存 | 当前页面、播放进度/运行中的 JS 内存、未完成的 GM 分片 |
| 分类筛选和收藏筛选偏好 | WebDAV 账号密码、调试日志、损坏存储副本、网络/页面缓存 |

GM 数据继续按配置 ID + 脚本 ID + 脚本 namespace/name 隔离；恢复保留 ID，文件名不重新生成。也备份有效的旧身份存储及未被当前配置引用的有效存储，因为仅从配置无法反推脚本元数据。遇到 `AtomicFile` 的有效 `.bak` 会读取其完整恢复值；不把 `.new` 或缓存目录中的未完成分片纳入归档。

脚本源码仍在打开配置时重新下载，因此恢复到另一台设备不保证脚本版本、网站登录、验证结果或网页表现完全相同。脚本 namespace/name 若由作者更改，GM 存储身份仍按现行规则变化。

## 版本冲突

上传前检查远端文件。已有备份需确认覆盖；若与本机最后同步记录不同，会明确显示“远端已有其他版本”，用户可以取消后改用远端恢复。

- 首次上传使用 `If-None-Match: *`，防止检查后另一设备抢先创建文件。
- 覆盖已有文件使用服务器提供的强 ETag 与 `If-Match`。若服务器返回 412，停止上传并要求重新检查，不改成无条件覆盖。
- 服务器没有提供可用于条件写入的强 ETag 时，允许读取备份，但拒绝覆盖已有备份。可使用一个空的独立备份目录；不声称支持该服务端的无冲突覆盖。
- 两台设备各自修改的数据不自动合并；恢复是按所选组件完整替换，不是增量导入。

## 完整性与恢复

ZIP 必含 `manifest.json` 和 `config.json`；按选项包含 `preferences.json`、`userscript-values/<hash>.json`。格式版本 2 的清单显式记录 `components`、UUID、创建时间、设备与 App 版本，以及每份正文的实际字节数和 SHA-256。继续读取版本 1 的全量备份，旧版 App 不能读取版本 2 的可选备份。

下载流同时检查声明和实际大小；解包只接受已知路径，拒绝绝对路径、反斜杠、路径穿越、重复或未知条目。全部条目须通过大小、CRC 和 SHA-256 检查，配置须通过现有模型校验，GM 文件须通过 UTF-8 与存储编码校验，再进入确认页。压缩包最多 512 MiB，解压正文合计最多 1 GiB，最多 4096 份 GM 存储；单份 GM 上限继续为 10 MiB。配置/偏好文本各最多 1 MiB。

应用恢复先关闭旧 WebView/脚本 host，再在共用 GM FIFO 队列中直接交换所选文件，避免旧实例的内存快照覆盖新文件。配置、GM 目录、偏好作为一组使用事务日志与原子文件替换；异常尝试回滚。事务仅临时保存回滚所需的旧配置、偏好和目录引用，不生成完整 ZIP，成功后删除旧数据。进程中断后，下次启动在创建浏览器前恢复未完成事务；如果仍无法回滚，阻止继续浏览并提供重新启动重试。事务提交后的大目录清理在后台进行。上个进程遗留的临时目录也在下次启动后台清理。

本版备份为未加密 ZIP。账号仅保存于 App 私有偏好；网络和备份日志不记录账号、密码或 GM 内容。WebDAV 和在线导入的请求取消、TLS 连接清理都在后台执行，界面关闭和切换账号不会在主线程关闭 HTTPS socket。

## 验证

单元测试覆盖 ZIP 往返、旧版兼容、可选组件与空存储、非法路径、清单/哈希错误、截断包、解压大小上限、非法 UTF-8、恢复回滚与启动事务恢复，以及 WebDAV Basic 认证、PROPFIND/MKCOL、HEAD/GET/PUT、创建目录竞态/权限失败、条件创建/覆盖、412、不支持覆盖的 ETag 和下载超限清理。

设备用例使用真实 Activity/原生按钮、本机 MockWebServer 与真实 GM 文件，覆盖大于 1 MiB 规则、跨设备状态替换、恢复不生成撤回备份、不读取将被替换的本机 GM 内容、旧自动备份清理且手动导出保留、偏好和 ID 保留、取消预览、无效备份不改变本机、远端并发修改拒绝、排队 GM 写入及 `.bak`、启动中断恢复、恢复过程中的 Activity 重建。模拟器测试不代表已对用户的实际 WebDAV 服务提供商验收。
