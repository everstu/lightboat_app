## 新增

- **应用内更新**：配置管理页底部可检查 GitHub 最新正式版，查看更新说明、下载并通过系统覆盖安装。安装前校验包名、签名和版本，关闭窗口可取消下载。
- **共享脚本库**：同一脚本可供多个配置使用，支持批量添加、独立启停和调整注入顺序，显示已保存配置的引用数量。
- **默认配置与备注**：可以明确设置启动时打开的配置，切换网页不会改变默认项；配置备注支持多行、查看和复制。
- **本地与 WebDAV 备份**：配置和脚本库必选，脚本数据及界面偏好可选，支持在另一台设备上恢复。
- **配置分类与收藏**：支持管理分类名称、删除分类、收藏筛选、置顶和长按拖动排序，记住上次筛选。

## 改进与修复

- 统一配置卡片、编辑器、脚本库及各类弹窗的紧凑样式，改善窄屏、大字体和横屏下的操作体验。
- 同一共享脚本跨配置共用 GM 数据；单次下载及每脚本存储上限提高到 10 MiB，大数据采用分块传输和按需读取。
- 调试日志支持关键词、来源和级别筛选，只保留最新 2000 条，减少长期运行的内存和磁盘开销。
- 修复页面导航期间脚本会话失效，以及部分加密 HLS 密钥和分片被错误识别导致的播放失败。
- 保留服务器验证页面的交互能力，并在重定向循环时提供“清除网页缓存并重试”。
- 加强导入、备份恢复及脚本数据损坏后的检查与恢复处理。

## 安装与升级

- 版本：**1.0.4（36）**；Android 8.0 及以上，系统 WebView 需支持提前注入。
- 下载 `lightboat-v1.0.4-debug.apk`。继续使用项目固定签名，可覆盖安装使用同一签名的旧版本并保留数据。
- 新版备份格式包含共享脚本库和多脚本引用，旧版应用可能无法导入新版备份。备份不加密，也不包含网站登录状态或脚本源码。
