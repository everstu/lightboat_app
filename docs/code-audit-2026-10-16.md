## 修复

1. **无后缀 HLS 不能正确播放。** 原先只依据扩展名和 MIME 判断清单；合法 `#EXTM3U` 被标成普通文本时，相对分片地址未改写。增加不消费原始数据的头部识别。实播又确认 Android 原生播放器会根据地址选择解析器，因此已知 HLS 直接使用 `.m3u8` 本机地址，首次识别的无后缀 HLS 通过 `Cache-Control: no-store` 的 302 跳转进入同一通道。无后缀清单因此会多一次读取；不保存页面或媒体内容缓存。
2. **清单大小计算不准确。** 改为统计实际输入字节，包含 BOM、CRLF 和无尾换行，修复超过 2 MiB 未拒绝及恰好达到上限却被拒绝的问题。二进制分片保持原始字节和 Range/206。
3. **GM 存储阻塞界面，坏文件阻止配置启动。** 文件读取和原子写入移至共用串行后台队列，旧 host 写入先于新 host 快照。损坏存储使用空快照继续启动，保留一份有大小限制的恢复副本；首次写入目录创建、现代 API 落盘确认、删除和重建后读取均已实测。
4. **跨 frame 的旧通知覆盖新本地值。** 本地写入未确认时不应用更早的远程通知，确认完成后继续正常同步。
5. **GM 请求排队超时与 abort 不及时。** 总超时从提交时计时，脚本侧超时主动取消原生请求；主动 abort 立即结束 Promise，迟到响应不再触发成功回调。默认 30 秒，零值和超长值按已声明的 120 秒上限处理。
6. **失败页面持续占用 WebView 和媒体会话。** 离开 WebView 错误回调后释放失败实例，使用实例和导航代数检查防止清理新页面。子资源证书错误只取消相应资源；主请求单独跟踪并显示证书错误，兼容取消后不触发通用错误回调的 WebView。
7. **部分诊断信息缺失。** 未配置脚本时也记录网页/媒体控制台错误；日志首次读取失败显示失败状态，空日志恢复成功后清除旧的失败文案。
8. **配置与身份边界不一致。** 长中文路径转换为 ASCII 后再次检查长度，避免保存后无法重新解码；异常 Chrome 版本片段不再生成无效 UA Client Hints。
9. **Release 名称可能与包内版本不一致。** 发布前读取 APK 构建元数据，拒绝标签与公开版本号不一致的产物。
